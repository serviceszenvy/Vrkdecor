# Sample portfolio images

These are **synthetic placeholder images**, generated procedurally. They are not
photographs, and they do not depict VRK Decor's work or any real event.

They exist so the portfolio layout, filters, gallery and lightbox can be
developed and reviewed before VRK Decor's own photography is available.

They are shown **only when Supabase is not configured**. As soon as a real
database is connected, the portfolio renders real published Designs and these
files are never referenced. They must be deleted before the production build.

## Files

- `<occasion>-<n>.webp` — 24 portfolio placeholders referenced by
  `lib/content/sample-portfolio.ts`.
- `hero-celebration.webp` — the placeholder behind the home page hero,
  referenced by `lib/content/hero-media.ts`. It is decorative, carries empty
  alt text, and the hero renders a brand gradient if it is absent.

They are regenerated by `scripts/generate-sample-images.py`.
